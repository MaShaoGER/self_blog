工业平面设计不靠装饰，靠**栅格与编号**。这句话写起来容易，落到代码里全是细节。

这篇文章记录一次版式实验：把产品目录、技术图纸、铭牌标签的排版语言，直接排成网页。

## 为什么是工业平面

传统博客的默认结构是"标题 + 摘要 + 卡片"。它安全，但也很少承载信息。工业平面提供了另一套语法：

- 编号系统（`NO.` / `FIG.` / `CAT.` / `REV.`）让条目可以被引用；
- 1px 结构线取代阴影，边界清楚且不占视觉重量；
- 等宽字承担所有数字与标签，让参数对齐。

> 信息密度不是把内容塞满，而是让每个元素都有位置和名字。

![归档标签的丝印样本](/uploads/2026/10/label-sheet-02.jpg)

### 三条硬约束

1. 不用纯黑纯白，避免刺眼；
2. 零圆角，或最大 3px；
3. 每屏的装饰性标记不超过 3 类。

## 栅格怎么落地

12 列栅格、24px 沟槽、32px 页边距。内容主栏 720px，侧栏 280px。首屏显示 40px 细网格，文章页关闭——阅读区不需要被网格干扰。

```css
.wrap {
  max-width: 90rem;
  margin-inline: auto;
  padding-inline: 2rem;
}
```

编号与图注一律用等宽字，字号在 10–12px 之间，字距 +0.06em。这个尺度在视网膜屏上仍然可读，同时不会抢正文的注意力。

## 写实控件放在哪

80 / 20 是这一版最重要的分寸：**页面 80% 保持平面，20% 的关键控件做写实质感**。

写实控件只出现在交互点——主题切换、订阅、搜索、分页、评论区。正文阅读区保持平面，读者不该在文章里被控件分心。

![等距设备线稿](/uploads/2026/10/schematic-01.jpg)

### 分寸

- 键帽按钮：3px 实体阴影，按下位移 3px；
- 凹槽输入框：内阴影刻痕，聚焦 2px 橙；
- 拨杆：轨道凹槽 + 橡胶手柄，两态。

全部用原生 `button` / `input`，保留键盘、焦点与 ARIA。写实是皮肤，不是替代。

## 下一步

先跑通四个断点（390 / 768 / 1024 / 1440），再验证深色主题与 `prefers-reduced-motion`。版式系统只有在自己被压力测试过之后，才算成立。
