# 多人账号与首页文案

更新日期：2026-10-22。

## 使用入口

- 登录：`/login`，现在需要用户名和密码。已有管理员密码会初始化成用户名 `admin`，无需另设密码。
- 账号管理：`/admin/accounts`，创建账号、调整显示名称与角色、停用 / 启用、重置其他账号密码。
- 我的账号：`/admin/devices`，查看自己的账号信息、修改密码、移除自己的设备。
- 站点设置：`/admin/settings`，修改站名、介绍、作者、首页铭牌、按钮、栏目和状态面板文字。
- 项目管理：`/admin/projects`，管理员新增、编辑和删除项目，直接更新前台展示。
- 全站导航与页脚也在「设置」中编辑，导航入口地址固定，修改显示文字；项目、导航、页脚均由管理员管理。

## 权限

| 操作 | 管理员 | 编辑 |
|---|---|---|
| 查看后台、管理文章 / 图片 / 评论 | 可以 | 可以 |
| 修改自己的密码、管理自己的设备 | 可以 | 可以 |
| 创建 / 停用 / 重置账号、调整角色 | 可以 | 不可以 |
| 修改站点设置与首页文案 | 可以 | 不可以 |

不开放访客注册。管理员分配用户名与初始密码；新建或重置的密码为 12–128 个字符。显示名称可修改，登录用户名保持稳定。系统阻止停用或降级当前管理员，并始终保留可用管理员。

密码重置、停用或角色变更会使目标账号的旧会话失效，启用后需重新登录。每人只能查看和移除自己的设备，「退出其他设备」不会影响其他成员。账号和设置页面有页面权限校验，保存操作也独立校验；隐藏导航不是权限边界。

## 首页文案

站点名称、站点描述、作者和站头一句话介绍继续在原设置中修改。新增 23 项首页文字，分为铭牌、导航与目录、状态面板三组。数字统计、归档年份跨度和更新时间从已发布文章生成，不手工修改。

旧 `settings.json` 自动补齐默认首页文案，原视觉内容保持兼容；局部保存不会清掉其他配置。首页文字上限 120 字，站点描述 300 字，必填项与类型在服务端校验；保存后立即刷新前台。

## 存储与迁移

账号使用原子 JSON 文件存储，不新增数据库和依赖。真实数据位于源码外的 `BLOG_DATA_DIR`（默认 `../self_blog-data`），其中 `accounts.json` 不入 Git，密码采用独立盐的异步 scrypt，文件权限为 `0600`。初始化只发生一次，账号文件损坏时停止认证，不用环境密码覆盖已有账号。

`BLOG_ADMIN_PASSWORD` 仅用于首次创建 `admin`；修改该环境变量不等同于重置密码。`BLOG_SESSION_SECRET` 继续负责会话签名，轮换会使所有账号退出。旧单管理员会话不再接受，升级后首次需要重新登录。

账号文件随 `data/` 备份，登录会话继续排除；备份包含密码哈希，应妥善保存。旧镜像忽略角色，回退前必须撤销所有会话。

口令存储参考：[Node.js scrypt 文档](https://nodejs.org/docs/latest-v24.x/api/crypto.html#cryptoscryptpassword-salt-keylen-options-callback)、[OWASP Password Storage Cheat Sheet](https://cheatsheetseries.owasp.org/cheatsheets/Password_Storage_Cheat_Sheet.html#scrypt)。
