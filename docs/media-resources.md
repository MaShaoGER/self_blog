# 视频、工程资源与三维模型

正式功能沿用博客原来的主题、导航和阅读布局。此前的 `/preview`、`/lab`、演示模型和样片入口已移除，不影响真实资源。

## 在文章里插入视频

进入文章编辑器，点击工具栏「插入视频」。

### 本地上传

1. 选择 MP4 或 WebM 文件，单文件最多 **200 MiB**。
2. 可填写资源名称，点击「上传并插入」。界面显示上传进度，可取消。
3. 成功后在打开弹窗前的光标位置插入视频引用，右侧预览可直接播放；手机可切到「预览」。

上传需要后台登录并通过同源校验。服务端检查实际流大小、文件头、MIME 与扩展名，不只相信浏览器声明；分块写临时文件，成功后原子落盘，失败/中断清理临时文件。不会整段视频读入内存，也不经过 4 MiB 的文章 Server Action。

视频存放在 `BLOG_DATA_DIR/uploads/videos/<随机UUID>.mp4|webm`，不进入源码仓库。对外地址为 `/uploads/videos/<UUID>.<扩展名>`；读取支持 GET、HEAD 和单段 Range（拖动进度），非法范围返回 416。网关或托管平台可能另有更低的请求限制；公网部署时需同步检查代理设置。

上传保留原始编码，不转码。容器正确不代表任意编码在浏览器可播，遇到不兼容编码时应先用剪辑软件转为适合网页的 MP4/WebM。

### 视频链接

切换「视频链接」，粘贴完整 HTTPS 地址：

- YouTube：普通观看页、`youtu.be`、Shorts 或官方 embed 地址。
- 哔哩哔哩：包含 BV/av 编号的完整视频页或官方播放器地址。`b23.tv` 请先打开，再复制完整视频页地址；博客不抓取任意短链。
- 外部直链：MP4、WebM、m3u8 可按路径识别。没有可识别后缀的签名直链需显式选择格式。

视频网站使用官方播放器，访客点击确认后才连接第三方；不提取原视频、不绕过付费/登录/地区/DRM 限制。嵌入失败时仍有重新加载和在平台打开入口。

本地上传和已支持的视频网站可直接预览。新的外部直链域名仍受 CSP 约束，首次登记后可能需要保存文章并完整刷新，让浏览器取得新的来源策略；HLS 分片/密钥的额外域名按下文配置。

## 上传、列目录与私有的区别

编辑器插入的视频会建立一个稳定资源 ID，默认 `visibility: public, listed: false`：

- 不出现在**匿名访客**的公开目录，避免未发布文章的附件被目录列出来。
- 知道引用/资源链接的人仍可访问；这是“不列目录”，不是保密存储。不要上传敏感视频。
- 已登录的后台账号仍可在资源库管理它；勾选「出现在公开资源目录」后，匿名目录才会列出。
- 真正限制后台账号访问时，将资源或其祖先目录改为 `private`。本地视频的字节接口也会检查关联资源的继承权限，不只保护元数据页；无有效索引的本地文件不对外提供。
- 本地视频响应使用 `private, no-store`，避免日后改私有时留下公共缓存授权。已经下载到他人设备的内容无法收回。
- 移除资源只移除索引，不自动删除上传或外部文件；磁盘文件随运行目录备份，清理磁盘时应先核实文章引用。

外部源站仍掌握它自己的权限。博客不能撤销已发出的 Cloudreve/OneDrive 签名地址，也不能使源站公开文件自动变私密。

## 工程文件浏览

- `/resources`：目录、面包屑、分页与文件预览。
- `/admin/resources`：管理员/编辑维护目录和资源索引。
- `/resources/<id>`：视频、图片、真实 GLB 或普通文件下载。
- 正式「项目」页有「浏览工程与素材」入口。

工程包可以作为一个文件夹，下面登记成片、模型、图片、工程文件和说明。外部文件填写 HTTPS 直链；可使用 Cloudreve 已生成的地址，博客不会转存外部大文件。

资源索引保存在 `BLOG_DATA_DIR/resources.json`，沿用原子写锁。损坏文件会阻止修改，不丢弃旧内容后覆盖。新字段 `listed` 缺省为 true，旧索引无需迁移。

`private` 沿所有祖先目录继承。子项标为 public 也不能绕过私有祖先；匿名元数据、访问地址和下载接口均不可访问。私有访问复用现有后台账号，不是匿名提取码系统。

## 三维模型

真实 GLB 预览使用 Three.js GLTFLoader 和 OrbitControls，点击后才加载。支持拖动旋转、缩放、平移、复位、方向键操作和主动开启的旋转；Escape 停止旋转，系统减少动态效果时禁用自动旋转。静止、离屏与后台会约束持续渲染。

优先使用体积适中的自包含 GLB，源站需允许跨域读取。当前不自动转换 Blender/AE/FBX，不下载 Draco/KTX2 等外部解码器。读取失败会显示错误，不使用内置演示模型冒充成功。

没有 3D 首页、试验皮肤或内置测试几何。真实模型只在对应资源中显示，正文保持原来的平面阅读体验。

## Markdown 引用

编辑器自动写入引用，无需手写 ID。也可手动引用已有资源：

```md
[查看工程](/resources/资源ID)
```

嵌入公开资源使用：

````md
```resource
资源的完整UUID
```
````

原始 HTML 仍关闭。围栏只接受完整 UUID，避免编辑过程中对不完整 ID 连续请求。公开文章只嵌入可匿名访问的资源；私有资源即使作者在后台预览也不嵌入公开正文。

## 网络与临时链接

CSP 保留原有脚本 nonce、object 禁止和防外站嵌套策略。外部媒体/模型读取来源来自已校验的登记资源 origin，iframe 仅允许 YouTube 与哔哩哔哩的官方地址；不保留已删除实验页的测试源白名单。

有些 Cloudreve/OneDrive/CDN 会重定向到其他域名，HLS 也可能引用另一台 CDN。可配置精确额外 origin：

```dotenv
BLOG_MEDIA_ORIGINS=https://cdn.example.com,https://media.example.com
```

仅填 HTTPS origin，不带路径、令牌和通配符。修改环境后重启；新增来源后完整刷新文档。

临时链接可在资源后台设置 ISO 有效期。过期返回 410，需发布者更新。没有 Cloudreve 实例地址/凭据时，不自动同步目录、生成或续签地址。

## API

| 方法 | 路径 | 用途 |
|---|---|---|
| POST | `/api/videos` | 已登录/同源；登记视频链接或流式上传本地视频，返回 `{ id, name, url? }` |
| GET/HEAD | `/uploads/videos/<UUID>.mp4或webm` | 关联索引授权后读取真实文件；GET 支持单段 Range |
| GET | `/api/resources?parentId=<id>&cursor=<cursor>` | 每页最多 50 项，无 source；匿名列表过滤 private 与 listed=false |
| GET | `/api/resources/<id>` | 授权后的元数据，无 source |
| POST | `/api/resources/<id>/access` | `{ "purpose": "preview" }` 或 `download`，授权后返回来源 |
| GET | `/api/resources/<id>/download` | 授权后跳转到已登记地址，不代理远端内容 |

视频链接请求 JSON 为 `{ "url": "https://…", "name": "可选名称", "format": "可选mp4/webm/hls" }`。本地上传请求体直接发送文件，Content-Type 为 video/mp4 或 video/webm，X-Upload-Name 为 encodeURIComponent 后的文件名；不是 multipart。

没有权限和不存在统一 404；过期直链 410，输入错误 400，超限 413，不支持类型 415，数据读取失败 500。写入接口还会返回既有的登录/同源拒绝响应。

## 范围与验证

沿用已有固定版本 three、@types/three、hls.js，无新增依赖。可运行 `pnpm test:resources`、`pnpm test:videos`、`pnpm typecheck` 与 `pnpm build`。

AE 工程目前只作文件分享，不解析合成、图层或插件。没有万能视频网站解析、转码服务、Cloudreve 自动同步或自动删除远端文件。
