# 工业设计平面风格参考

理解：不是把网页做成"可点击的拟物机器"（那是 `industrial.md` 里 Teenage Engineering 那类），
而是把**工业平面设计**——产品目录、技术图纸、手册、标签、档案——的版式语言直接排成网页。
你发的五张图（产品渲染、硬件面板、90s 设备线稿、板卡贴纸、数据标签）都属于这一类。

## 一、工业平面档案 / 技术图录（最贴你给的图）

1. **People's Graphic Design Archive — NFK 电缆目录** — https://peoplesgdarchive.org ★★
   1960s 荷兰电缆厂产品目录扫描；页面上是"扫描封面网格 + 元数据表（Title / Date / Designer /
   Client / Country / Format）+ 绿色状态标签"。**档案图录的排版样本**：图 + 编号 + 规格逐条列出。
2. **Design Reviewed** — https://www.designreviewed.com ★
   黑底 + 档案照片 + 大段说明；"150 years of visual communication, 11,000 artifacts" 的档案站语气。
3. **Computer History Museum — Online Collections** — https://www.computerhistory.org/collections/catalog/ ★
   红/黑/纸白，图片网格 + On View 标签；技术档案的展陈式排版。
4. **eMuseum（Museum für Gestaltung Zürich）** — https://www.emuseum.ch
   瑞士设计博物馆的藏品图录：海报/物品网格 + 极简筛选；平面作品当数据展示。
5. **Internet Archive — The Manual Library** — https://archive.org/details/manuals ★★
   350 万份设备/软件手册扫描：Radio、Sony、Samsung、Philips 封面网格。**技术手册封面的宝库**。
6. **Google Patents** — https://patents.google.com/patent/USD544884 ★★
   专利图纸页：3/4 视图线稿、FIG. 编号、Claims、PDF 下载；**线稿 + 编号 + 技术说明**的语法直接可抄。

## 五、"工业设计平面"的视觉语法（你给的图 + 以上站点的共性）

- **网格**：8/12/16 列，可见或半可见的网格线；模块化拼贴（图片块 + 文字块 + 色块）。
- **字体**：condensed / grotesk 大写标签；mono 数值与编号；正文可用窄栏无衬线。
- **编号系统**：MODEL NO. / FIG. / ITEM / DATE / SER. / CAT. ——一切皆可编号。
- **色彩**：暖灰/纸白/近黑打底，单一安全橙（#e8531f 附近），荧光绿/暗红只作状态点。
- **图形元素**：条码、QR、裁切线、虚线安全框、十字定位标记、刻度尺、警示斜纹、贴纸、印泥错位。
- **图像**：产品渲染/平铺摄影/扫描件/线稿；统一的去饱和或单色处理；图注 mono 小字。
- **排版习惯**：左对齐、紧行距大标题、正文窄栏、页脚成块的规格信息、页码/章节号。
- **质感**：纸张扫描噪点、丝印磨损、轻微套印偏移、阴影极浅。

## 六、落到博客的版式方向（三选一或组合）

**A. 目录 / 索引式首页**
首屏是"站点名称 + 型号 + 一句说明"，下面是文章索引表：
`NO. / TITLE / DATE / CAT. / READ`，行间 1px 线，分类用色块/LED 点；
右侧或页脚放"规格块"（更新频率、文章数、RSS、版权）。

**B. 手册 / 数据页式文章页**
左侧固定"参数栏"（DATE / WORDS / TAGS / VERSION / 修订记录），
正文单栏 62ch，章节编号 01/02，配图统一 1px 边框 + mono 图注（FIG. 01），文末"规格表"。

**C. 档案网格式列表**
把文章当作藏品：封面图统一比例（4:3 或 1:1）、去饱和/单色、卡片下方编号 + 标题 + 年份；
适合摄影/长文并重的博客，首页即一份"档案目录"。

通用细节：纸白 `#f2efe9`、墨黑 `#17171a`、安全橙 `#e8531f`、灰 `#b9b4aa`；
字体可用 Archivo Narrow / Oswald / IBM Plex Sans + IBM Plex Mono；
中文标题用思源黑体 Heavy，数字与英文点缀 mono；纸纹噪点 3–5%，印刷错位 0.5–1px。
