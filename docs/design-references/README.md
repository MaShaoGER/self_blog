## 一、编辑 / 纸感（最贴近本项目方向）

1. **Maggie Appleton** — https://maggieappleton.com
   暖米白底 + 衬线大标题 + 一句话自述；数字花园按 Essays / Notes 分区；
   少量亮色只落在链接上。首屏没有卡片，只有字。
2. **A Working Library（Mandy Brown）** — https://aworkinglibrary.com
   书籍式排版、细发丝线；Selected essays 列表 hover 才浮出摘要，信息密度收得很紧。
3. **Asterisk Magazine** — https://asteriskmag.com
   米黄纸底 + 一张手绘/拼贴插画定调 + 衬线正文；杂志式栏目，不是卡片流。
4. **The Marginalian** — https://www.themarginalian.org
   黄/黑/米白强对比头条区，左侧 donate 栏，典型编辑博客布局；大色块只用一次。
5. **Craig Mod** — https://craigmod.com
   信件 / 书 / 订阅混排，专题长文自带排版；订阅被当作一等公民。
6. **Robin Sloan** — https://robinsloan.com
   暖底衬线标题 + 一句话人设（"a creative industrialist"）。
7. **Robin Rendle** — https://robinrendle.com
   报纸式排版与彩色标题；首页实验页（Photos 文件浏览器）本身值得看。

## 五、可落地到 self_blog 的手法

- 首屏：一句大号 serif 自述，下面直接接最新文章；不要 hero 卡片。
- 文章列表：发丝线分隔，日期 / 阅读时长用 mono 小字；hover 再浮出摘要。
- 阅读页：行宽 62–68ch；首段可放大作 lede；文内图去圆角，配 1px 细边与 mono 图注。
- 色彩：陶土橙只用于链接、hover、强调与选中态，大面积保持纸色。
- 纸张颗粒：SVG `feTurbulence` 叠加，opacity 0.02–0.04，`position: fixed` 不随滚动。
- 深色主题：墨黑底 + 纸色文字 + 同色橙；避免纯 #000 / #fff。
- 动效：只保留一次入场（标题淡入或下划线展开），其余 hover 微反馈；尊重 `prefers-reduced-motion`。
