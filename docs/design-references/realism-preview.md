# 拟真风格预览记录（已撤下）

归档于 2026-11-11：用户决定正式项目沿用原博客主题，不保留测试样式。`/preview`、`/lab` 和测试模型均已删除；本文仅记录此前试验，不是当前可访问功能。视频、目录与真实 GLB 预览已独立并入正式项目，见 [媒体资源说明](../media-resources.md)。

## 当时的设计方向

用户反馈：上一版工作台预览过于复杂、混乱，希望保留原版整洁感，只留下适量写实机械感和符合直觉的操作。

本版回到原有站头、站名与简介、文章目录、页脚的结构。沿用现有纸白/墨黑/安全橙与字体体系。以阅读为主，不再增加“先操作一台机器，再找文章”的流程。

## 保留与移除

- 保留：原版导航与页脚、平面文章列表、键帽按钮和主题拨杆。右侧只放一个按需加载的三维材质实验，不增加选文流程。
- 移除：独立阅读器、滑块选文、上一篇/下一篇选文键、纸张叠层、插画缩略图、便笺侧栏、手写签名与装饰贴片。
- 清理：已删除不再使用的 `reading-deck.*`、`paper-library.*`，没有保留隐藏的旧实现。
- 正式首页和文章数据保持不变；视频、工程资源与 Three.js 能力另见 [媒体资源说明](../media-resources.md)，后台增加独立资源管理入口。

## 操作与动效

- 浏览目录：普通锚点，直接到文章列表。
- 阅读文章：有真实文章时点击标题直接进入文章页；没有已发布文章时，明确标注的三篇样文通过原生 details/summary 展开试读，不写入正式数据。
- 主题：复用原版真实拨杆，不增加第二套主题状态。
- RSS：真实订阅入口，不增加仿播放器或音量控件。
- 键帽：按下时短行程下沉、阴影收缩，释放后克制回位；主题手柄有短暂的机械到位反馈。
- 文章行只改变底色与展开指示方向，不漂浮、不倾斜、不编排段落入场。
- 遵从系统减弱动态效果设置，保留状态反馈而取消位移过渡。
- 滑块只适合字号、音量或进度等连续值，不用来选择离散文章；没有实际功能的旋钮不展示。
- 三维：点击后加载，默认不自动旋转；支持拖动、缩放、复位和方向键，Escape 停止旋转。没有功能绑定的装饰不冒充操作控件。


## 后续改造顺序（待确认后实施）

1. 确认这版页面密度与写实比例，再考虑把控件手感迁入正式站点，不重做布局。
2. 阅读页只增强真实交互点：代码复制、目录定位、评论提交。正文保持平面、稳定。
3. 后台只增强保存、发布、上传的操作反馈，不改成仪表盘或硬件控制台。

判断标准：先能自然地找到并读完文章，之后才感受到细节；不为展示拟真效果新增入口、说明和操作步骤。
