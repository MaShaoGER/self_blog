规则 / RULES
  • 80 / 20：页面 80% 保持工业平面（纸白、栅格、mono 编号），20% 关键控件写实。
  • 写实控件只放在交互点：主题切换、订阅、搜索、分页、评论区、播放/进度；正文阅读区保持平面。
  • 光源统一左上；高光 1px 白、暗边 2px 黑；阴影不超过 3 层。
  • 按压 80ms、位移 2–3px；拨杆 120ms；旋钮可带 60ms 惯性。
  • 必须用原生 button / input / a，保留键盘与 ARIA；写实是皮肤不是替代。
