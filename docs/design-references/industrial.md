## 一、工业硬件品牌官网（写实产品摄影 + 硬件式界面）

1. **Teenage Engineering** — https://teenage.engineering ★最接近你发的图
   灰漆底 + 产品渲染图居中 + 顶部手绘线框图标菜单（products / store / latest / finder / gallery）；
   标题 "the beauty of evolution." 用克制的 sans。整体像产品说明书封面。

## 六、这套语言的核心（从你发的图里拆出来）

- 底色：暖灰/金属漆 `#d8d4cc`、`#b9b4aa`、`#8f8a82`；暗部近黑 `#1a1a1c`；面板米色 `#e8e2d6`。
- 唯一强调色：安全橙 `#e8531f` / `#ff5a1f`；辅以 LCD 荧光绿 `#c8e85a`、暗红拨档 `#7a2b22`。
- 字体：condensed 大写标签（Oswald / Barlow Condensed / Archivo Narrow）+ mono 数值
  （IBM Plex Mono / Space Mono）；正文可用 Inter 或 IBM Plex Sans；中文回落思源黑体/苹方。
- 结构：1px 面板分缝、2–5px 圆角、螺丝孔、刻度线、虚线安全框、条码/QR、型号编号、
  贴纸（轻微旋转 + 撕边 + 印刷错位）。
- 纹理：金属/纸噪点（SVG feTurbulence，opacity 0.03–0.06）、丝印磨损、轻微色差。
- 交互：键帽下压（2px 位移 + 阴影收缩）、拨杆/旋钮状态、LCD 段码刷新、开机自检（尊重 reduced-motion）。

## 七、映射到博客（待确认方向后细化）

- 首页：像设备铭牌/开机界面——站名当 MODEL，状态栏（日期 / 文章数 / RSS 状态），
  一块"LCD"区域滚动显示最新文章。
- 文章列表：照 TE Guides 的参数表——编号 / 标题 / 日期 / 时长 / 分类 LED 色。
- 文章页：数据手册——左侧固定参数栏（日期、字数、标签、版本），正文 62ch，图注 mono，章节编号。
- About：铭牌 + 规格表（作者参数、站点信息、权利声明）。
- 深色主题：机柜/暗室；浅色主题：喷漆金属面板。
- 组件：按钮=键帽、开关=拨杆、标签=贴纸、分割=面板分缝。
