在工业设计里，版本号不是"好看的小标签"，而是一条责任链：REV.01 改了什么、谁批的、为什么改，都能查回去。

网页很少这么做。我们习惯 `git log`，但那是对开发者说的，不是对读者说的。

## 读者需要知道什么

- 这篇文章什么时候写的；
- 后来改过没有；
- 改了什么性质的内容。

这三个问题，用一张三行的修订表就能回答。

```ts
type Revision = {
  rev: string;      // REV.02
  date: string;     // 2026-10-18
  note: string;     // 补充栅格章节
};
```

## 编号的分配方式

文章的编号（`NO.042`）一旦分配就不回收。删掉的文章留空号，和档案管理一样——空缺本身也是信息。

> 编号一旦可以复用，它就退化成序号了。

## 结语

编号系统的价值不在视觉，而在**可引用**。当读者能说"NO.042 的第三节"，讨论才真正开始。
