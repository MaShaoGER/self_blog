这篇是整个站点的搭建记录。写法参照设备手册：先给结论，再给参数，最后才是原理。

结论是——**先把 token 定死，再写页面**。跳过这一步，后面每个组件都会各自发明一套间距与颜色。

## 起点：把颜色收敛到七个值

最初的调色盘有十二个颜色。删到七个之后，页面反而更有辨识度。

| 角色 | 值 | 用量 | 用途 |
|---|---|---|---|
| PAPER | `#EFEBE3` | 68% | 页面底 |
| INK | `#17171A` | 20% | 正文与结构线 |
| MINT | `#D3E4D6` | 8% | 区块底 |
| SAFETY | `#E8531F` | 3% | 主强调 |
| SIGNAL | `#FF2D6F` | 1% | 编号与标记 |
| GREY | `#B7B1A5` | — | 次级信息 |
| CABINET | `#111113` | — | 深色主题底 |

数量本身不是目的。真正的约束是：**任何一个新颜色，都要能回答"它替代了哪一个角色的工作"**。

### 对比度

正文对比度要 ≥ 4.5:1。橙底白字只有 4.8:1，小字就必须换黑字，或者把橙加深到 `#C9430F`。

```css
:root {
  --accent: #e8531f;        /* 大面积强调 */
  --accent-ink: #c9430f;    /* 小字与链接，保证 AA */
}
```

## 栅格：12 列不是装饰

12 列的好处是可整除：2、3、4、6 都能均分。实际用到的只有三档：

- 主栏 720px + 侧栏 280px（文章页）；
- 四列等宽（精选区）；
- 满宽单栏（参数表）。

```tsx
<div className="grid gap-x-6 md:grid-cols-[minmax(0,1fr)_17rem]">
  <div className="min-w-0">{children}</div>
  <aside className="hidden md:block">{meta}</aside>
</div>
```

`minmax(0, 1fr)` 里的 `0` 很关键。少了它，长标题会把栅格撑破——这是最常踩的一个坑。

> 栅格的价值不在于"对齐好看"，而在于**当你犹豫放哪时，它已经替你决定了**。

## 字体：三种，各司其职

| 角色 | 字体 | 规格 |
|---|---|---|
| 展示标题 | Archivo 800 | 64px / 0.95 / -0.02em |
| 正文 | Inter 400 | 17px / 1.75 |
| 标签与编号 | IBM Plex Mono 500 | 11px / +0.08em |

中文标题回落到系统黑体（PingFang SC / 微软雅黑）。这不是妥协——思源黑体的子集体积仍然偏大，而系统黑体在粗字重下的观感已经足够接近。

### 为什么移除衬线

早期版本用 Fraunces 做标题。它在"暖纸 + 陶土橙"的方向里很成立，但换成工业平面之后就冲突了：衬线的曲线与结构线、编号系统互相打架。

字体是方向的一部分，不是可以单独优化的变量。

## 组件：先做契约，再做页面

在写第一个页面之前，先定下这几类组件：

1. **标记**：叉框、裁切角标、刻度尺、条码、编号前缀；
2. **版式**：参数表行、图注、状态行、年份分组；
3. **控件**：键帽按钮、凹槽输入、拨杆、LCD、LED。

前两类保持完全扁平。第三类才承担写实质感——这就是 80/20 的落地方式。

```tsx
// 键帽按钮：3px 实体阴影，按下位移 3px
.keybtn {
  box-shadow:
    inset 0 1px 0 rgba(255, 255, 255, .85),
    0 3px 0 var(--key-edge),
    0 5px 8px rgba(23, 23, 26, .12);
}
.keybtn:active { transform: translateY(3px); }
```

### 标记的使用纪律

每屏最多三类标记，而且必须承载信息。条码旁边的数字、图注旁边的编号、刻度尺旁边的比例——**标记的意义来自它旁边的数据**，否则就是噪声。

## 双主题

深色不是把颜色反过来，而是换一套材质隐喻：页面变成机柜黑，面板变成 `#1A1A1C`，网格线与边框透明度要单独调。

```css
.dark {
  --paper: #111113;
  --line: rgba(232, 228, 218, .13);
  --grid-line: rgba(232, 228, 218, .045);
}
```

浅色的 `rgba(23,23,26,.14)` 直接搬到深色会完全看不见。这是第二个常踩的坑。

## 踩坑清单

1. `minmax(0, 1fr)` 缺失导致栅格撑破；
2. 深色主题下沿用浅色的 alpha 边框；
3. 中文字体 `font-synthesis` 导致假粗体发虚；
4. `prefers-reduced-motion` 只关了 transition，忘了 animation；
5. 移动端后台的固定底栏被 `safe-area-inset` 遮挡。
